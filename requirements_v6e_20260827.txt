# Verified working requirements for this repo's torchax/JAX TPU scripts (NOT
# torch_xla) on a single v6e-4 TPU VM: wan_tx_splash_attn.py (Wan2.1 T2V) and
# qwen_image_edit_tx.py (Qwen-Image-Edit). Originally captured 2026-08-27 while
# bringing up wan_tx_splash_attn.py; peft was added afterward for
# qwen_image_edit_tx.py's --lightning_lora support.
# Regenerated and validated 2026-08-27 with:
#   python wan_tx_splash_attn.py --model_id Wan-AI/Wan2.1-T2V-1.3B-Diffusers --num_inference_steps 2
#   python qwen_image_edit_tx.py --image <img> --prompt "add a rainbow in the sky" --num_inference_steps 40
# torch is CPU-only on purpose: actual compute happens on TPU via torchax/JAX, torch is
# just used as the tensor/module frontend, so no CUDA build is needed.
#
# Verified install procedure (re-tested end-to-end from a brand new venv on 2026-08-27,
# confirmed a full run of wan_tx_splash_attn.py works with no manual intervention):
#   1) pip install torch==2.8.0 torchvision==0.23.0 torchaudio==2.8.0 \
#        --index-url https://download.pytorch.org/whl/cpu
#   2) pip install --no-deps -r requirements_v6e4_torchax.txt
#   3) pip install -e <path-to-this-diffusers-repo>
#
# Step 2 MUST use --no-deps for the whole file, not just for maxdiffusion: this file is
# a full `pip freeze` of an already-working, self-consistent environment, so every
# transitive dependency is already pinned explicitly here. Without --no-deps, pip's
# resolver evaluates maxdiffusion's own setup.py, which pins huggingface-hub==0.30.0 --
# that conflicts with transformers' requirement of huggingface-hub>=0.34.0 (also pinned
# in this file) and pip aborts with ResolutionImpossible. huggingface-hub==0.30.0 is an
# overly strict/stale pin in maxdiffusion's metadata; 0.34.4 (pinned below) works fine
# in practice.
#
# NOTE: this repo's own top-level requirements.txt is stale (dates from the torch_xla
# era, before the switch to torchax) and pins jax to an unreachable April-2025 nightly
# wheel plus torch-xla, which is not what wan_tx_splash_attn.py actually uses.
